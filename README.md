# Course Registration System

## 📌 Project Overview

The Course Registration System is a Java GUI application developed for October 6 University.

The system allows students to log in and register for courses through a simple and user-friendly graphical interface.

## 🔐 Login System

Before logging in, the user must first create an account.

The username and password entered during the sign-up process are displayed in the console.

When the user tries to log in, the entered username and password are checked using conditions against the previously registered information.

If the entered data matches, the user can successfully log in.
Otherwise, the login process is not allowed.

## 🎨 Change Background

The application includes a **Change Background** button.

The button allows the user to change the background of the application between four different colors using a list of colors.

## 📚 Course Levels

After logging in, the user can access four course levels:

- Level 1
- Level 2
- Level 3
- Level 4

Each level contains four different courses.

## 📝 Course Registration

The user can select any course they want to register for.

When a course is selected, its name appears in the text area at the bottom of the page.

The user can also remove a selected course, and it will disappear from the text area.

## 🔄 Scrolling

The course page supports both:

- Vertical scrolling
- Horizontal scrolling

This allows the user to navigate through the page and view all available courses easily.

## ⬅️ Back Button

A **Back** button is available to return to the previous page.

## 🛠️ Technologies Used

- Java
- Java GUI
- Eclipse IDE

## 🗄️ Database

This project does not use a database.

The username and password are temporarily stored and compared within the Java program.
